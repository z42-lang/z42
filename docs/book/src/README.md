# z42 文档

z42 的文档分三本书。先按**你要做什么**挑一本。

| 你要做什么 | 读哪本 |
|---|---|
| **学怎么用 z42** —— 从安装、第一个程序到建工程、发布 | [学习手册](https://z42-lang.github.io/z42/learn/) |
| **查规则** —— 语法怎么写、某个 API 什么签名、命令有哪些旗标、清单字段全表、错误码 | [语言与库参考](https://z42-lang.github.io/z42/reference/) |
| **改 z42 本身** —— 编译器/VM/标准库怎么实现的、为什么这样、在哪改 | [实现内幕](https://z42-lang.github.io/z42/internals/) |

---

## 学习手册

按学习顺序读一遍就会用。每一章的代码都来自仓库里的 `examples/`，由门禁逐条真实运行校验——
书里印的输出就是它实际跑出来的。

**[打开学习手册 →](https://z42-lang.github.io/z42/learn/)**

## 语言与库参考

不读实现也能用对。按主题组织、可跳读，规则完整。

| 部分 | 涵盖 |
|---|---|
| 语言 | 语法、类型、泛型、模式匹配、异常、可见性、特性…… |
| 标准库 | 各包的公开 API：类型、方法签名、用法、**不支持的用法** |
| 工具链 | `z42` / `z42c` / `z42b` 命令面、`z42.toml` 字段全表、运行时旋钮清单 |
| 嵌入 | C ABI 契约、原生互操作 |
| 测试 | `[Test]` 怎么写、`z42 test` 怎么用 |
| 附录 | 错误码全量表 |

**[打开参考手册 →](https://z42-lang.github.io/z42/reference/)**

## 实现内幕

要动这块代码才需要读。按子系统、按机制组织。

| 部分 | 涵盖 |
|---|---|
| 编译器 | 架构、绑定器层次、泛型推断、特性流水线、自举 |
| 运行时 | 执行模型、解释器/JIT、GC、对象 ABI、嵌入、平台抽象 |
| 产物格式 | zbc / zpkg / zsym 完整规格 |
| 标准库 | 实现分层与 native 预算、包划分与 interop 归属、API 准则 |
| 工具链 | z42b、launcher、REPL、部署形态、平台 export |
| 测试体系 | 测试框架与 runner、跨平台测试、执行 profile 矩阵 |
| 开发基础设施 | xtask、构建编排、GREEN gate、性能门禁、CI、打包发版 |
