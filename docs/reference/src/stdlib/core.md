# z42.core —— 核心类型与预导入工具。

> 包路径 `src/libraries/z42.core/`；命名空间 `Std`

Std 命名空间随每个脚本隐式可用（隐式 prelude）：根目录的 String / Math / Array /
Convert / Guid / Version / Object / Type 等核心类型，以及子目录的 Primitives
（Int32 / Double 等）、Delegates（Func / Action 等）、Protocols（IComparable 等）。
String 的索引与长度按 Unicode 标量（char）计；数值与位运算走 Math / BitConverter；
反射走 Type / Enum；平台与运行时能力查询走 Platform / OperatingSystem。

一部分成员是 VM 内建 extern intrinsic（标 `[Native]`，如 String.Length / Math.Sqrt /
Platform.OS），其余是纯 z42 脚本（如 String.Contains / Math.Abs / Array.Sort）。
本命名空间没有统一的不支持列表；各类型的边界见其成员注释与 stdlib 文档页。
