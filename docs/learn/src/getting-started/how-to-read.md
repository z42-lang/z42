# 阅读说明

起步部分到这里结束，接下来进入语言本身——**呈现方式会变**：前面几章手把手带你建文件，
后面要展示的写法太多，改为只截出正在讲的那几行。

这一页把本书余下的约定一次说清——代码从哪来、怎么跟着做、终端画面怎么读。
**看一遍就够，后面各章不再重复。**

## 按顺序读

每一章只用到前面讲过的内容，从头往后读最省力。需要跳读的是**参考手册**，不是这本书。

## 代码从哪来

书里的代码没有一行是凭空写的，全都来自仓库
[`examples/`](https://github.com/z42-lang/z42/tree/main/examples) 目录下**可以直接运行**的文件，
目录结构与章节一一对应。你总能知道眼前这段代码是哪个文件里的：

- **前面几章**（你刚读完的起步部分）手把手带你做，正文里直接说「新建一个名为 `hello.z42`
  的文件」，并把**整个文件**展示出来——照着敲就能跑。
- **从下一章起**要展示的写法太多，改为把出处写成**代码块第一行的注释**：

  ```text
  // examples/basics/variables/types/types.z42
  int    count = 42;
  double ratio = 0.5;
  ```

  复制代码时这行注释会一起带走，正好留住它的来处。

  这时**书上展示的通常只是文件里的一个片段**，只截出正在讲的那几行。完整可跑的程序就是那个
  文件本身——它带着片段里省掉的外壳：

  ```text
  using Std.IO;          ← 引入用到的命名空间

  void Main() {          ← 程序入口
      ...                ← 书上展示的片段在这里
  }
  ```

这个外壳就是 [Hello, World](hello-world.md) 那一章讲过的 `using` 与入口函数。
**照着书上的片段敲时，记得把它放进 `Main` 里**，或者直接去仓库拿完整文件。

## 跟着做的两种方式

**方式一：自己建文件。** 新建一个 `.z42` 文件，把代码写进去，`z42 run <文件>` 跑起来。
起步部分的几章会手把手带你做一遍。

**方式二：把仓库拉下来直接跑。** 示例都是现成可运行的：

```sh
git clone https://github.com/z42-lang/z42.git
cd z42/examples/basics/variables/types
z42 run types.z42
```

改一改再跑，是最快的学法。

## 终端画面怎么读

书里的终端画面长这样：

```text
$ z42 run hello.z42
Hello, World!
```

- **`$` 开头的行是你敲的命令**，后面几行是它打印的输出。
- 命令失败时最后会多一行 `[exit: 1]`，那是**退出码**（成功是 `0`，书里省略不写）。
- 偶尔出现的 `[..]` 表示这一行里有会变的内容（版本号、耗时、临时目录），照着敲不必一致。

**这些输出不是手写的**，全部来自示例的真实运行，并由持续集成逐条校验——你照着敲，看到的就是
书上写的。

## 遇到看不懂的写法

手册讲「怎么用」，讲到够用为止。**完整的语法规则、标准库 API、命令行选项、工程清单字段、
错误码**都在[语言与库参考](https://z42-lang.github.io/z42/reference/)里，书中讲到某条规则时
会直接给出对应链接。

另外两个会反复出现的标记：

- **`> 熟悉 C# 的读者请注意：…`** ——z42 与 C# 不一样的地方，单独点出来。
- **⚠️ / 🔴 开头的段落**——当前实现的坑或缺口。z42 还在 1.0 之前，有些规则说好了但编译器还
  没强制，书里不回避，直接写明白。
