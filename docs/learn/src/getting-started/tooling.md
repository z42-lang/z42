# 开发环境

前三章一直在用「任何编辑器 + 终端」。这一章把手边的工具配齐：让编辑器认识 z42 代码，
学会用 REPL 随手试一段代码，以及——最重要的——**读懂编译器报的错**。

## 编辑器

z42 自带一份 VS Code 集成，随 SDK 一起装好了，一条命令启用：

```sh
z42d install vscode
```

它会把语法支持装到 `~/.vscode/extensions/z42.z42-lang/`，**重启 VS Code** 后 `.z42` 文件就有了
语法高亮和成对括号、注释快捷键（`Cmd`/`Ctrl` + `/`）。重复执行这条命令即更新。

> 目前提供的是**语法高亮与编辑配置**。还没有语言服务器，所以**没有跳转定义、自动补全、
> 实时错误提示**——错误要靠下面讲的 `z42 run` / `z42 build` 来看。
>
> 用别的编辑器也不影响：z42 源文件就是普通文本，没有编辑器也能正常构建运行。
> 手边没有 z42 高亮时，**按 C# 高亮**通常就够用了。

## REPL：随手试一段代码

不想为了试一行代码建个文件，就开 REPL：

```sh
z42 repl
```

进去之后输入什么就求值什么，回车看结果。输入的代码会**实时着色**。
要退出敲 `.exit`，或者按 `Ctrl-D`。

REPL 里以 `.` 开头的是**元指令**（不是 z42 代码）：

| 元指令 | 作用 |
|--------|------|
| `.help` | 列出全部元指令 |
| `.vars` | 看当前绑定了哪些变量 |
| `.types` | 看这个会话里声明过哪些类型 |
| `.usings` / `.using <ns>` | 看 / 加 `using` |
| `.reset` | 清空会话状态，从头再来 |
| `.clear` | 清屏 |
| `.exit` / `.quit` | 退出 |

会话是**有记忆**的：前面声明的变量、函数、类型，后面可以接着用。

只想算一个表达式、不想进交互界面，用 `-c`：

```console
{{#include ../../../../examples/getting-started/tooling/repl/run.console:eval}}
```

> `-c` 只收 z42 代码，**不认元指令**——`z42 repl -c ".help"` 会把 `.help` 当表达式去解析然后报错。
> 元指令只在交互界面里有效。

## 读懂编译错误

这是这一章最该花时间的部分。z42 的报错格式是固定的，认准它就能快速定位。

拿一个有两处错误的文件：

```z42
{{#include ../../../../examples/getting-started/tooling/errors/bad.z42}}
```

运行它：

```console
{{#include ../../../../examples/getting-started/tooling/errors/run.console:errors}}
```

逐段拆开看：

```
  bad.z42(4,13): E0402: cannot assign string to Int32 (var-decl)
  ~~~~~~~~ ~ ~~  ~~~~~  ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
  文件     行 列  错误码  说明
```

- **行、列都从 1 开始**，列指向出问题的那个位置——`(4,13)` 就是第 4 行第 13 个字符，
  也就是 `"abc"` 的开头。
- **`E` 开头的是错误**，编译不会产出任何东西；退出码是 `1`。
- **一次报全部**，不是遇到第一个就停——上面一次列出了两个。先改第一个，因为后面的错误
  有时是它引起的连锁反应。
- 开头那行 `z42c build: 2 error(s) in bad.z42` 是**汇总**，告诉你一共几个、在哪个文件。

这两个错误分别是：

| 码 | 意思 | 这里为什么 |
|----|------|-----------|
| `E0402` | 类型对不上 | `int n` 要的是整数，给的却是字符串 `"abc"` |
| `E0401` | 名字找不到 | `Consle` 拼错了，应该是 `Console` |

**`E0401` 是最常见的错误**，来源通常是三种：拼错了名字、忘了写 `using`、或者那个名字确实不存在。

> **想查某个错误码的完整含义**，见参考手册的
> [错误码全量表](https://z42-lang.github.io/z42/reference/appendix/error-codes.html)。

## 小结

- `z42d install vscode` 装编辑器语法支持，重启编辑器生效；目前只有高亮，没有语言服务器。
- `z42 repl` 开交互会话随手试代码，`.` 开头是元指令；`z42 repl -c '<表达式>'` 只算一个表达式。
- 编译错误的格式是 `文件(行,列): E错误码: 说明`，一次报全部，先改第一个。
- 错误码的完整清单在参考手册里，遇到不认识的码就去查。

起步部分到这里就结束了——你已经能装好 z42、写程序、建工程、配好手边的工具。
