# 前言

这本手册带你从零开始使用 z42：安装工具链，写出第一个程序，再一步步学会语言本身、标准库，以及怎样把程序发布到各个平台。

## 适合谁读

- 写过至少一门编程语言（C#、Java、Rust、Python、TypeScript 都可以）的开发者；
- 想了解 z42 能做什么、怎样上手的人。

z42 的语法与 C# 相近。如果你熟悉 C#，大部分代码一眼就能看懂；不同之处书里会专门指出。

## 怎么读

按章节顺序读最省力：每一章只用到前面讲过的内容。书里的代码和终端输出都来自仓库里可直接运行的
示例，并由持续集成逐条校验——你照着敲，看到的就是书上写的。

代码放在哪、怎么跟着跑、终端画面怎么读，都在起步部分末尾的
[阅读说明](getting-started/how-to-read.md)里 —— 读到那里时花两分钟看一遍，
后面各章就不再重复这些约定。

## 版本

手册跟随 z42 的最新版本（nightly）。z42 还处在 1.0 之前的快速迭代期，如果你用的是较旧的版本，个别命令和输出可能与书中不同，建议先[更新到最新版](getting-started/install.md#更新)。

## 想查得更细？

手册讲「怎么用」，讲到够用为止。**语法规则、标准库 API、命令行选项、工程清单字段、错误码**
的完整表格，都在[语言与库参考](https://z42-lang.github.io/z42/reference/)——遇到「这里还能写什么」
的疑问就去那里查。

编译器与虚拟机**怎么实现**的是另一回事，不在本手册也不在参考手册的范围内——
真要读，那是[实现内幕](https://z42-lang.github.io/z42/internals/)那本书。
