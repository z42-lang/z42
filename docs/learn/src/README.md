# 前言

这本手册带你从零开始使用 z42：安装工具链，写出第一个程序，再一步步学会语言本身、标准库，以及怎样把程序发布到各个平台。

## 适合谁读

- 写过至少一门编程语言（C#、Java、Rust、Python、TypeScript 都可以）的开发者；
- 想了解 z42 能做什么、怎样上手的人。

z42 的语法与 C# 相近。如果你熟悉 C#，大部分代码一眼就能看懂；不同之处书里会专门指出。

## 怎么读

按章节顺序读最省力：每一章只用到前面讲过的内容。每章的代码都是完整、可以直接运行的，放在仓库的
[`examples/`](https://github.com/z42-lang/z42/tree/main/examples) 目录下，目录结构与章节一一对应，可以直接拿来运行和修改。

书中的终端输出都来自这些示例的真实运行结果，并由持续集成逐条校验——你照着敲命令，看到的就是书上写的。

## 版本

手册跟随 z42 的最新版本（nightly）。z42 还处在 1.0 之前的快速迭代期，如果你用的是较旧的版本，个别命令和输出可能与书中不同，建议先[更新到最新版](getting-started/install.md#更新)。

## 想深入实现？

手册讲「怎么用」。语言特性的完整规则、编译器与虚拟机的设计原理，见 [z42 语言与实现](https://z42-lang.github.io/z42/)。
