A/B（同机交错 ×3）总停顿 `--large` −1.4% / `lh` −0.2%，最大停顿在逐轮离散度之内，
墙钟 / RSS 持平，产物逐字节一致。关掉自适应 nursery 重测同样无收益。

**M3 笔记里「固定成本大头 / 原型 −8%」两条都不成立**——灰队列只占卡表那笔账的 6.8%。
