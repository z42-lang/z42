# runtime/src — 运行时模块职责

## 职责

本目录编译为唯一运行时包 `z42`。按职责直接组织模块；`lib.rs` 声明库模块，`main.rs` 动态加载宿主入口。可选执行与分析组件在 `../crates/z42-interp`、`../crates/z42-jit` 和 `../crates/z42-profiler`，静态产物解析在 `../crates/z42-zpkg`。

## 功能索引

| 目录 | 唯一职责 | 边界 |
|---|---|---|
| `host/` | 嵌入与应用宿主服务 | CLI、Rust、C 共用加载和调用；当前仍有组件管理公开面与默认 VM 装配职责待收口 |
| `component_abi.rs` / `component_bridge.rs` | 同构建跨库协议与最小桥 | C 布局表、构建身份及核心布局，独立组件使用，不经 host 转出 |
| `components/` | VM 内部能力访问与生命周期 | 内部 api、角色绑定、工厂、发现、依赖、实例与租约；不实现具体后端 |
| `config/` | 配置声明、解析与构造快照 | 汇总旋钮和来源优先级，转换为各子系统的显式输入 |
| `context/` | VM 共享核心与每线程视图 | 组合状态、注册/销毁、访问入口和扩展状态容器；默认资源装配归 host |
| `exec/` | 引擎共享的执行机制 | 帧、调用、异常、初始化执行及共享指令语义；不包含具体后端 |
| `metadata/` | 每 VM 的链接元数据 | 类型/函数身份、解析、派发缓存、静态字段与初始化事实；二进制解析归 z42-zpkg |
| `loader/` | 包与 native 库加载机制 | 读取、合并、惰性解析、native 代码寿命与加载上下文；宿主默认策略归 host |
| `threads/` | 线程协作与暂停协议 | mutator 注册、safepoint、同步和根服务适配；OS 原语归 PAL |
| `object/` | 对象和值的表示 | 值、对象头、布局、数组、字符串及存储原语；回收策略归 GC |
| `gc/` | 堆分配与垃圾回收 | 根追踪、写屏障、代际/STW/增量回收 |
| `corelib/` | 内置托管服务实现 | builtin 提供者与对象协议实现；宿主资源通过服务接口注入 |
| `interop/` | 原生能力注册/查询与调用桥接 | 提供方目录、Tier 1 ABI 与编组；文件装入归 loader |
| `pal/` | 平台与 OS 原语 | 文件系统、动态库、信号、内存与线程平台差异 |
| `diagnostics/` | 运行时诊断状态与观察接口 | 计数、事件、暂停统计和采样接口；具体分析与输出归 profiler |

## 基础用法

嵌入端依赖 `z42::host`。内部模块通过所有者提供的窄接口协作；组件能力的具体实现与管理子模块不进入消费者依赖。
新增实现先确定状态所有者和机制/策略边界，再选择目录；不按调用方重复实现同一流程。

组件能力的入口是内部 `components::api`，具体实现不进入消费者依赖。当前公开面、双向引用与命名缺口见
[运行时模块边界](../../../docs/internals/src/runtime/module-boundaries.md)，其中明确区分当前代码与未实施目标。

## 如何测试验证

仓库根运行 `./xtask test runtime` 和 `./xtask test`。宿主或组件边界变更还运行 `./xtask package sdk --verify` 及真实静态/动态组件验证。
