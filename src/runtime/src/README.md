# runtime/src — 运行时模块职责

## 职责

本目录编译为唯一运行时包 `z42`。按职责直接组织模块；`lib.rs` 声明库模块，`main.rs` 动态加载宿主入口。可选执行后端在 `../crates/z42-interp` 和 `../crates/z42-jit`，静态产物解析在 `../crates/z42-zpkg`。

## 功能索引

| 目录 | 唯一职责 | 边界 |
|---|---|---|
| `host/` | 嵌入与应用宿主服务 | 所有嵌入接口/类型从这里提供；CLI、Rust、C 共用加载、装配和调用流程 |
| `components/` | 可选组件协议与生命周期 | 工厂、身份校验、静态/动态发现、依赖、实例与租约；不实现解释器或 JIT |
| `config/` | 配置声明、解析与构造快照 | 汇总旋钮和来源优先级，转换为各子系统的显式输入 |
| `context/` | VM 共享核心与每线程视图 | 组合状态、注册/销毁、访问入口和扩展状态容器；默认资源装配归 host |
| `exec/` | 引擎共享的执行机制 | 帧、调用、异常、初始化执行及共享指令语义；不包含具体后端 |
| `metadata/` | 每 VM 的链接元数据 | 类型/函数身份、解析、派发缓存、静态字段与初始化事实；二进制解析归 z42-zpkg |
| `loader/` | 包定位与加载机制 | 读取、合并、惰性解析与加载上下文；宿主默认策略归 host |
| `threads/` | 线程协作与暂停协议 | mutator 注册、safepoint、同步和根服务适配；OS 原语归 PAL |
| `object/` | 对象和值的表示 | 值、对象头、布局、数组、字符串及存储原语；回收策略归 GC |
| `gc/` | 堆分配与垃圾回收 | 根追踪、写屏障、代际/STW/增量回收 |
| `corelib/` | 内置托管服务实现 | builtin 提供者与对象协议实现；宿主资源通过服务接口注入 |
| `interop/` | 托管与原生调用桥接 | Tier 1 ABI、编组、回调与 native 扩展协议；嵌入入口归 host |
| `pal/` | 平台与 OS 原语 | 文件系统、动态库、信号、内存与线程平台差异 |
| `diagnostics/` | 运行时诊断状态与观察接口 | 计数、事件、暂停统计和采样接口；具体分析与输出归 profiler |
| `profiler/` | 性能分析实现与输出 | CPU 采样、堆摘要、快照和保留链；不拥有执行状态 |

## 基础用法

嵌入端依赖 `z42::host`。内部模块和独立后端直接引用所属职责模块，不经总括模块或兼容转发。新增实现先确定状态所有者和机制/策略边界，再选择目录；不按调用方重复实现同一流程。

## 如何测试验证

仓库根运行 `./xtask test runtime` 和 `./xtask test`。宿主或组件边界变更还运行 `./xtask package sdk --verify` 及真实静态/动态组件验证。
