# iface_null_mark_crosspkg（正例：接口成员的 `?` 跨包携带）

`carry-iface-null-marks` 的正例。消费方经**接口收者**调用标了 `?` 的成员，按规矩
「先存局部再查」⇒ 编得过、跑得出结果；未标 `?` 的成员直接解引用 ⇒ 同样编得过。

覆盖三种承载形态：方法返回位、接口**属性**的 getter 返回位、以及一个 🔒 未标的对照。
（形参位那一侧的义务落在**实现方**，由 `iface_null_mark_crosspkg_impl` 钉。）

⚠️ **这条用例单独存在时证明不了任何事**：机制完全没接通时它照样全绿。
判别力在两条负例上，见各自 README。
